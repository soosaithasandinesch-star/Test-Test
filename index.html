Auf GitHub Pages bereitstellen

Folge diesen einfachen Schritten, um deinen Taschenrechner kostenlos auf GitHub zu veröffentlichen:

  1. GitHub Account: Melde dich auf github.com an.
  2. Neues Repository: Klicke auf das "+"-Symbol oben rechts → New repository.
  3. Name vergeben: Nenne es z.B. taschenrechner und erstelle es (Public).
  4. Datei hochladen: Klicke auf "uploading an existing file". Lade diese Datei unter dem Dateinamen index.html hoch.
  5. GitHub Pages aktivieren: Gehe in deinem Repository zu Settings → Pages (linke Menüleiste).
  6. Quelle wählen: Wähle unter Build and deployment / Branch den Branch main (oder master) und klicke auf Save.

Nach 1-2 Minuten ist deine Webseite unter https://dein-username.github.io/taschenrechner/ weltweit erreichbar!
